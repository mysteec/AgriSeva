# 🌱 AgriSeva – Plant Disease Detection System

AgriSeva is a deep learning-based web application that detects plant diseases from leaf images.

## 🚀 Features
- Upload plant leaf image
- Predict disease using trained CNN model
- User-friendly interface

## 🧠 Tech Stack
- Python
- TensorFlow / Keras
- Streamlit

## 📂 Dataset
Dataset used: https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset

## ▶️ How to Run

pip install -r requirements.txt  
streamlit run main.py

## 📌 Note
Dataset is not included due to size. Please download it from the above link.
